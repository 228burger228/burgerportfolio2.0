## Как работает

1. Пользователь кликает на кнопку "Открыть галерею ↗" на карточке
2. JavaScript вызывает `openGallery()` с ID модали
3. Модаль открывается с `opacity: 1` и `pointer-events: auto`
4. Для карусели (graphic-gallery): кнопки "‹" / "›" переключают изображения через `transform: translateX()`
5. Счётчик обновляется по мере навигации
6. Закрытие: клик на X, overlay или Escape

## Адаптивность

- Галереи работают на всех экранах
- На мобильных: `max-width: 90vw`, `max-height: 90vh`
- Кнопки навигации достаточно крупные для сенсора
- Свайп-навигация может быть добавлена позже
