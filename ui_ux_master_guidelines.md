# UI/UX Master Guidelines — Dmitry Burger Design System
*Свод стандартов разработки и проектирования интерфейсов («Бизнес-Премиум»)*

---

## 1. Фундаментальные принципы (Art Direction & No AI-Slop)

1. **Цвет тратится строго на данные (`Leonxlnx/taste-skill`):**
   - 90% площади интерфейса — глубокая монохромная база (`#09090b` для фона, `#18181b` для карточек, `#27272a` для внутренних плашек).
   - Акцентные цвета (`#38bdf8` синий, `#10b981` изумрудный, `#f59e0b` янтарный) используются строго функционально: статусы, активные контролы, ключевые метрики.
   - Никаких кислотных неоновых градиентов, розово-фиолетовых пятен и размытий.

2. **Инженерная тактильность (`GyverLibs/GyverPortal`):**
   - Каждый контрол (кнопка, таб, тумблер, чип) дает мгновенную тактильную обратную связь:
     - `:active { transform: scale(0.97); }`
     - Пульсирующие LED-индикаторы рабочего статуса (`● LIVE`, `● В сети`).
     - Время отклика UI не превышает 16–50 мс. Нулевой оверхед, чистый нативный DOM (Vanilla JS + CSS3).

3. **Световые микрофаски и глубина слоев (`Vuetify` & `Linear`):**
   - Премиальный эффект матового стекла и титана достигается за счет микрофаски по верхнему краю:
     `box-shadow: inset 0 1px 0 rgba(255, 255, 255, 0.12), 0 4px 16px rgba(0, 0, 0, 0.25);`
   - На ховере карточка слегка приподнимается (`translateY(-4px)`), а фаска усиливается до `inset 0 1px 0 rgba(255, 255, 255, 0.22)`.

4. **Единый геометрический стиль иконок (`Lucide Icons`):**
   - Все иконки строятся по сетке 24×24 px с толщиной обводки `stroke-width="1.75"` или `2`.
   - Закругленные окончания (`stroke-linecap="round"`), гармонирующие со скруглениями кнопок.
   - Полное табу на эмодзи в качестве системных интерфейсных иконок.

## 2. Безусловные правила взаимодействия (Жесткие табу)

> [!CAUTION]
> 1. **Табу на заглушки (`No Stubs`):** Никаких "Lorem ipsum", выдуманных тестовых плашек или фиктивных кейсов. Если чего-то не хватает — сразу задавать прямой вопрос пользователю.
> 2. **Табу на выдуманные факты:** Никаких историй про травмы руки (скриншот был из фильма), никаких несуществующих биографических фактов. Вся информация — только реальная и выверенная.

---

## 3. Производственный чеклист качества (`ui-ux-pro-max-skill`)

- [x] **Доступность и контраст:** Контрастность текста не менее 4.5:1 (WCAG AA/AAA). Текст вторичного уровня (`#a1a1aa`, `#94a3b8`) всегда легко читается на темном фоне.
- [x] **Кликабельность:** `cursor: pointer` на всех интерактивных элементах (кнопки, вкладки, карточки, чипы).
- [x] **Фокус клавиатуры:** Четкий контур `:focus-visible { outline: 2px solid var(--color-accent); outline-offset: 2px; }`.
- [x] **Тач-зоны:** На мобильных экранах (до 640px) минимальный размер области нажатия — 44×44 px.
- [x] **Неломающаяся верстка (`Resilient Text Wrap`):** Никаких обрезанных слов посередине контейнера. Использование `flex-wrap: wrap`, безопасных отступов `gap` и корректного переноса текста.
- [x] **Уважение к `prefers-reduced-motion`:** Мгновенное отключение декоративных анимаций для пользователей с чувствительностью к движению.

```css
  /* База */
  --color-bg-primary: #09090b;
  --color-bg-surface: #18181b;
  --color-bg-elevated: #27272a;
  
  /* Акценты */
  --color-accent: #3b82f6;
  --color-accent-hover: #2563eb;
  --color-success: #10b981;
  --color-warning: #f59e0b;

  /* Микрофаски */
  --edge-card: inset 0 1px 0 rgba(255, 255, 255, 0.12), 0 4px 16px rgba(0, 0, 0, 0.25);
  --edge-card-hover: inset 0 1px 0 rgba(255, 255, 255, 0.24), 0 20px 40px rgba(0, 0, 0, 0.45);
  --edge-button: inset 0 1px 0 rgba(255, 255, 255, 0.25), 0 2px 4px rgba(0, 0, 0, 0.2);
}
```
